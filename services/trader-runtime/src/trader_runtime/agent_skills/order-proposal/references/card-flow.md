# 下单卡流程细节

## 卡片字段

- 合约（代码与中文名）、方向（买/卖、开/平）、手数、价格方式（限价/对手价/市价 Protection）、有效期。
- 开仓卡可带 `protection`（`stopLossPrice` / `takeProfitPrice` 至少一个）：卡上显示"止损 X / 止盈 Y · 成交后自动挂上"，替代默认的风控参考价一行。方向与最小变动价位在出卡时校验（多单 止损<委托价<止盈，空仓相反），错了中文拒绝不出卡。
- 卡上带确认与放弃两个操作；语音通话中卡片带"语音确认截止时间"。
- 打字说"取消这张卡/算了/不要了"：调 `reject_proposal`（proposalId、proposalVersion 照抄系统说明里的待确认卡），与点"放弃"同一接口；返回 status=rejected 才算作废。混合句先作废再做其余部分。AI 没有确认工具，确认只能用户点卡或语音说"确认"。

## 确认时效

- 网页/桌面：卡片一直可确认，报价过期（quote_stale）会拒绝并保留卡片等新报价。
- 语音：念完卡片后按设置的确认窗口（默认 15 秒）等待"确认/取消"；超时自动放弃。

## 常见失败码的中文说法

| 码 | 人话 |
|---|---|
| quote_stale | 行情报价过期，等新报价再确认 |
| market_session_closed | 现在不在交易时段 |
| price_limit_touched | 触及涨跌停，不能按这个方向下 |
| approval_expired | 确认超时，卡片已失效 |

## 风险规则立场（owner 2026-09-12 决定）

模拟账户不设平台级/账户级风险规则：无合约白名单、无单笔/每日亏损上限、无截断时间。没有提议风险规则的工具，设置里也没有风险规则；替代方案是给具体持仓挂止损单（order-ops 的 set_simulation_stop_loss）。
