# 提醒（price-alerts）

三种提醒都列在提醒面板“我的提醒”一张表里：到某个价（到价提醒）、碰到我画的线（画线提醒）、按条件（条件提醒）。用户问“能设什么提醒 / 自定义提醒”时把这三种都说出来。

到价提醒：用户点一下、说一句就能盯价：合约涨到或跌到目标价时，软件在对话里发消息、桌面弹通知（可关）、通话中直接口播。按账号记，跟行情不跟交易账户；只提醒，从不下单。

历史回放里同样可用（2026-10-03）：只限本次回放的合约（别的合约被拒，中文原因原话转告），按回放最新价判方向、按回放时间触发；提醒记在回放自己的账上，随回放一起消失。

画线提醒（2026-10-31）：用户在图上自己画的线可以“碰到就提醒”（线的右键或样式条“这条线被碰到时提醒我”，接口 `POST /api/market/alerts {drawingId}`）。`list_price_alerts` 的这类提醒带 drawingId，回执写“碰到画的线”；斜线跟着线走，挪线提醒跟着改，删线提醒一起删。用户要给某条线设提醒时请他在线上右键点一下；你自己只按价位设普通到价提醒。

条件提醒（2026-10-25）：用户的条件里除了价格还有别的（指标、均线、金叉死叉、放量、突破区间、几根 K 线……），就是一条条件提醒——用界面命令打开提醒编辑卡 `strategyEditor: {new: true, reminder: true, ask: 用户原话}`（app_call `POST /api/app/ui/commands`），整句原话原样交给它（价格条件也在里面），不要另外拆出一条到价提醒，也不要说“到价提醒做不到、得写成策略”。卡里只有条件和提醒时段，开始提醒由用户在卡上点；它存成 `plan.reminderOnly` 的策略，只能“只提醒”（confirm / auto 回 409 strategy_reminder_only），列在“我的提醒”，不在我的策略。用户说“只响一次 / 每根 K 线都提醒 / 今天收盘前有效 / 整张自选表都盯着”时用 `strategyEditor: {choose: {repeat, until, watchlist}}` 点选（不经 AI 设计），开始仍由用户点。条件提醒随策略功能开放（档位没开“策略管理与监控”时如实说）。

## 何时用

- 用户问能设什么提醒、要设自定义提醒：说清三种（到价、碰到画的线、按条件），再问他要哪种条件。
- 用户的提醒带价格以外的条件："5 分钟 KD 金叉提醒一下""放量突破开盘区间高点就提醒我""降到 3010 并且 MACD 死叉才提醒"→ 条件提醒（见上）。
- 用户要盯一个价："螺纹涨到 3150 提醒我""跌破 3100 告诉我""到 3200 说一声"。
- 用户查自己的提醒："我有哪些提醒""设了几个""螺纹那条还在吗"。
- 用户删提醒："删掉螺纹的提醒""那条不要了"。

## 何时不用

- 问现在的价格 → 行情与合约查询（market-lookup）。
- 到价自动下单（条件单）→ 没有这个功能，如实说明只能提醒；要交易走 下单出卡（order-proposal）；按条件自动交易是策略（strategy-management）。
- 成交播报、桌面通知开关、收盘前持仓提醒、风险度提醒、保本提醒的触发线 → 偏好设置（preferences）。
- 策略信号提醒（盯策略而不是盯价）→ 策略信号解读（strategy-signals）。

## 步骤

1. 到价：`create_price_alert`：symbol 可传合约代码或品种名（品种名自动取当前主力合约，对不上时先 `search_instruments`）；price 必须在该合约的最小变动价位上；direction 可省（按最新价自动判定涨到/跌到）。
2. 回执里有已设内容和现价，向用户复述"已设：螺纹2701 涨到 3150 提醒，现价 3112"。
3. 查与删：`list_price_alerts` 列出生效中和最近已触发的；`cancel_price_alert` 删生效中的（id 从列表拿）。
4. 被拒绝（价位不在跳上、方向与现价矛盾、超过 20 条上限、主连代码）时把中文原因原话转告，不要换个参数重试。

## 安全边界

- 只提醒不下单：本技能的任何工具都不创建委托、不改持仓、不碰风控。
- 上限 20 条生效提醒是数量上限，不是风险规则；到达上限照实转告。
- 用户没说目标价就先问，不要按现价猜一个。
- 条件提醒只打开编辑卡、带原话；开始提醒、保存都由用户在卡上点。

## 典型说法

- 螺纹涨到 3150 提醒我
- 跌破 3100 告诉我
- 我有哪些到价提醒
- 5 分钟 KD 金叉提醒一下
- 能帮我设一个自定义提醒吗
- 删掉螺纹那条涨到 3150 的提醒

## 反例（不该触发）

- 螺纹现在多少钱（查行情，走 market-lookup）
- 涨到 3150 就帮我开一手（下单，走 order-proposal）
- 提醒我每一笔成交（成交播报偏好，走 preferences）
