# UI 命令词汇表

## 面板与页面

- `panel`: ai（对话）/ strategy（策略）/ news（新闻）/ debate（辩论：多 AI 辩论页，游客与回放中不能开）/ order（下单：五档 + 下单票 + 本合约持仓）/ positions（持仓），一次一个；null 关闭。旧值 depth（原价格阶梯，已并入下单面板的五档）仍接受，按 order 打开。
- `view`: trade（交易台）/ review（复盘）/ board（报价）三个主页面切换；历史回放不是 view，用回放接口与回放窗口。
- `positionsTab`: positions / orders / fills（持仓面板与底栏三页签；fills＝成交，旧值 trades 仍接受）；`fillsSource`: all / manual / card / ai / strategy / stop / liquidation（成交按来源筛选；liquidation＝本站模拟盘强平）。
- `strategyTab`: library / running / detail（策略面板 我的策略 / 正在运行 / 选中策略的结果页；旧值 lab＝原实验室，打开结果页的“试几组参数比一比”）。
- `strategyEditor`: {open? | new? | edit:"<strategyId>", start?: blank / habits / template:<模板id>, answers?, ask?:"一句话", focus?, save?, close?}——策略编辑卡（新建或修改策略都用它，电脑放在策略面板里、编辑时面板约占窗口 3/4，左列表单、右列策略流程图与回测；手机布局是盖住底部标签的整屏页）：new 新建（起点默认按我的习惯，成交不够 5 笔就空白），edit 修改（卡片改不了的规则原样保留，存为新版本），ask 补一句（表单空时生成整份计划，已有内容时只改相关字段，改到的高亮、不直接保存），focus 把表单定位到流程图的一块（同点方块：basics / entry / exit / sizing，或 trigger / entryLong / entryShort / action / stop / take / trailing / breakeven / scaleOut / timeTakeProfit / maxHold / closeBeforeEnd / exitRules / limits；卡没开或取值不认识被拒），save 存为草稿，close 关闭；一条命令可组合，按 close → open/new/edit → start → answers → ask → focus → save 执行。上线运行仍由用户点（打开上线对话框）。快照 state.strategyEditor（各字段〔含 sizingMore、有修饰的条件行的 modifiers〕、aiFields、prefill、backtest 四格、flow 流程图〔触发、开多 / 开空条件组、开仓、各平仓方式与回测触发次数、底部说明〕、focus、canSave、missing、questions）。
- `strategyTemplate`: 只剩 {restore: true}（结果页里来自模板的策略恢复模板默认）；模板画廊并入编辑卡的“从模板”（strategyEditor start: template:<id>）。`strategyIdea` / `strategyGuide` 已下线，会被拒并提示改用 strategyEditor。
- `strategyLab`: {open | run | labId | choose}——结果页的“试几组参数比一比”（云端三组；快照 state.strategyLab）。
- `news`: {tab: desk / flash / news / data, pinnedSymbol?, flashFilter?, flashSort?, deskRejudge?, deskSource?}——新闻面板（调研 / 快讯 / 资讯 / 研究数据）；flashFilter = product / watch / macro / all（当前品种 / 持仓与自选 / 宏观 / 全部），flashSort = time / impact（按时间 / 按影响），只给筛选或排序也切到快讯页。deskRejudge: true 等同点调研页的“按最新消息重新判断”（一小时一次与当日次数限制不变，回执看 state.news.desk.rejudge 的 message）；deskSource: 事实 id（如 M.price）展开资料来源并高亮那一条；两者都切到调研页。判断“可能过时”只是提示（state.news.desk.stale），不要替用户反复重判。“看快讯”“打开快讯”“看新闻要点”走固定表（今日新闻要点在快讯页最上面）。
- `researchDebate`: 多 AI 辩论页（电脑是右侧栏“辩论”打开的整页、至少半个窗口，同 panel: debate；手机是调研页上的整屏子页），一次一项：{start: 事件 id}＝快讯“重要”行的“研讨”（事件 id 来自 GET /api/research/flash 的 events[].id；品种由 Runtime 按事件查出，不看当前图表的品种，“持仓与自选”里别的品种的事件也一样），{start: "desk"}＝今日判断旁“让 AI 们辩一轮”，{start: "event"}＝当前品种最新一条重要快讯（“讨论一下这条”）；同一事件同一品种当天只辩一次、今日议题资料没变时直接打开已有结果。{open: 研讨 id} 打开一次辩论（以前的辩论里的一格也是它），{rerun: true} 再辩一轮（新跑一次，计入当日次数），{close: true} 收起辩论页（手机是返回）。回执只说明请求已发出（state.researchDebate.request.status：sending / started / reused / refused + message）；四位分析师先同时写报告，再多方开场、空方回应、多方反驳、空方反驳依次写出来，最后由裁判判，约 2 到 3 分钟后才有结论——进行中看 state.researchDebate.step（analysts / turn1…turn4 / judge）、analysts（报告写完几份）与 speaking；写完的报告卡片用 disclosure debate-analyst-technical / supply / flow / news 展开，结论再读 state.researchDebate.status 或 GET /api/research/debates/{id}，不要反复发起。写进今日判断与停止是业务接口 POST /api/research/debates/{id}/adopt、/cancel；只有用户要求时才写进今日判断。游客不能用。
- `disclosure`: 具名折叠卡（voice-call、voice-mute、chat-history、strategy-new（打开 / 关闭策略编辑卡的新建）、strategy-ask-ai（结果页的“跟 AI 说怎么改”）、strategy-editor-trades / strategy-editor-more / strategy-editor-sizing-more / strategy-editor-advanced / strategy-editor-backtest（编辑卡里的“查看这 N 笔”、③ 怎么平仓的“更多”、④ 仓位与时段的“更多”、只读的高级规则、回测明细——手机是点底部回测四个数弹出的面板）、strategy-editor-picker（某条条件一侧的指标选择器，必须带 id＝组:第几条:left|right，如 entryLong:1:left；方向确认 / 复位的条件是 entryLong-align:1、entryLong-rearm:1（选择器再加 :left|right）；手机打开该条的底部面板并停在那一侧；上升 / 下降 / 等于的右边没有）、help-tip（一个“?”说明，必须带 id＝说明 key，如 strategy-editor:trailing；快照 state.disclosures 里 help-tip:<key>）、strategy-editor-section（手机编辑页四段与策略流程块，id＝basics / entry / exit / sizing / flow，一次展开一段）、strategy-editor-condition（手机编辑页某条条件的底部面板，id＝组:第几条，如 entryLong:1）、strategy-run-log、protection-status、order-depth（下单面板的五档折叠）、flash-calendar（快讯页“本周重要数据”展开全部）、flash-dropped / news-dropped（快讯页 / 资讯页“AI 筛掉了 N 条”折叠行，按原因列出被筛掉的条目）、flash-minor / news-minor（收起的次要消息）、flash-event / news-event（一个合并事件的各家报道，id＝事件 id）、flash-orig / news-orig（翻译过的英文标题的“原文”折叠，id＝条目 / 报道 / 手机事件 id）、desk-fundamental / desk-macro / desk-reports / desk-sources（调研页底部的基本面、宏观、相关报道、资料来源四个折叠，电脑与手机调研页同名）、debate-sheets / debate-sources / debate-stats / debate-log / debate-judge（多 AI 辩论结果页底部的裁判怎么取舍、五份底稿〔手机为底稿与来源〕、资料来源、研讨战绩、研讨记录；需辩论页打开）、chart-periods-more（周期行放不下时“更多”的浮层；切周期仍用 duration）、unlinked-notes（复盘页末尾“未关联的补充”折叠，有这类补充时才可用）、routine-delete（设置 → 记忆 → 我的流程一行的删除确认，id＝流程 id；确认删除由用户点）、research 等），open 开合；strategy-run-log 可带 id（运行实例 id）。
- `dialog`: 具名对话框（strategy-launch 上线对话框等），open 开合；旧名 strategy-designer 打开 / 关闭选中策略的策略编辑卡。
- `chatSession`: {new: true} 新对话；`aiFilter` 已退役（对话面板只放对话），仍接受但只打开对话面板。
- `ordersHistory`: true 展开委托历史。
- `mobileTab`: ai（AI 首页：今天概况、待确认置顶、带筛选的时间线）/ chat（AI 对话，与 panel: ai 同一状态）/ research（调研）/ market（看盘）/ strategy（策略：正在运行 / 我的策略两个分页，用 mobileStrategyTab 切）/ me（我的）；旧值 notify（原通知标签）打开 AI 首页并保持筛选，快照回报 ai——只对手机布局的窗口（快照 state.mobileLayout 为 true）有效，电脑布局 rejected；手机布局下打开侧边面板、切 view、底栏和浮动 AI 动态卡的命令 rejected。快照 state.mobileTab。没登录的游客在手机上也是手机布局（默认 market）：只能看盘和调研，ai / strategy / me 显示“登录后使用”页，chat 要登录。
- `mobilePage`: order（下单页，当前合约；确认才下单）/ positions（持仓与委托）/ review（复盘摘要）/ briefs（我的 → AI 简报推送：推送开关与订阅品种） / install（安装到桌面引导：按浏览器给步骤、安卓一键安装或微信等 App 内的换浏览器遮罩；快照 `state.installEnvironment`，游客也可打开；安装本身由用户在浏览器完成）/ lab（回测结果页：最近一次比较的几组参数、样本内 / 样本外与过拟合风险，选用走 POST /api/strategy-labs/{labId}/choose，上线与电脑同一校验、执行方式固定出卡确认；快照 `state.mobileLab {labId, chosen}`）/ reminders（提醒页，同 `reminderCenter: {open: true}`）/ push（我的 → 锁屏提醒：这台设备的开关与发一条试试、已开的设备；提醒哪几类与显示金额和手数在 `settingsPage: notify`；快照 `state.pushSupport`、`state.pushSubscribed`；游客不可开；开启必须用户手势，发一条试试走 `POST /api/app/push/test`）/ accounts（设置·账户，交易账户切换）/ memory（设置·记忆）/ appearance（设置·界面，外观与字号）/ help（使用说明卡），null 关闭——只对手机布局有效，电脑布局 rejected；快照 state.mobilePage。手机布局下 `positionsTab`/`fillsSource`/`ordersHistory` 落到持仓与委托页、`ticketMode`/`selectPosition` 落到下单页、`reviewExpand`/`reviewFilter`/`reviewSelect` 落到复盘摘要页；下单页止损/止盈折叠是 `disclosure: ticket-protection`；看盘的合约列表是 `dialog: contract-drawer`，合约与周期用 `symbol`/`duration`/`chartView`。
- `reviewDay`: "YYYY-MM-DD"——打开复盘（电脑复盘页、手机复盘摘要页）并把“今日复盘”块切到那个交易日（须在 `GET /api/account/daily-review` 的 `days` 里，否则 rejected；快照 `state.review.dailyReview`）；块底部“怎么算的”是 `disclosure: review-how`；重新生成、记住 / 不对是业务接口（见 review-summary 技能）。
- `mobileMarket`（2026-10-09，手机布局；一次一项，先切到看盘标签）：`{view: quotes|multi|single}` 报价 / 多图 / 单图；`{board: watchlist|main|SHFE|DCE|CZCE|CFFEX|GFEX|INE}` 报价板块；`{columns: [...]}` 报价数值列 1–4 个（last / changePercent / change / openInterest / bid / ask / volume / openInterestChange）；`{layout: four|periods|six}` 多图布局；`{cell: {index, symbol?, duration?}}` 改多图一格（symbol null＝自动补位，同合约 4 周期里 symbol 切当前合约）；`{subPane: kd|macd|rsi|oi|cci|volume}` 单图下显示的副图（没选的替换正在显示的）；`{subPanes: true|false}` 开关副图设置面板。值记在偏好 `ui.mobileMarket` 与 `chart.subPaneList`，快照 `state.preferences`；面板 `disclosures.mobile-subpanes`，报价列 `disclosure: mobile-quote-columns`，多图一格 `disclosure: mobile-chart-cell`（id 0–5）。
- `mobileStrategyTab`: running / mine——手机版策略页的分页（先切到策略标签；快照 state.mobileStrategyTab）。我的策略顶上“新建策略”，每条“编辑 / 回测 / 上线…”；新建与编辑用 `strategyEditor`（手机上是整屏页）。
- `mobileLab`: {labId}——打开手机版回测结果页看指定的一次比较（labId 来自 `GET /api/strategy-labs`；电脑布局 rejected）。
- `mobileNotifyFilter`: all / fill / brief——切手机版 AI 首页时间线的筛选（原通知页）并打开 AI 标签、滚到时间线（电脑布局 rejected；旧值 reminder 打开提醒页）；快照 state.mobileNotifyFilter，state.mobileUnread 是提醒中心的未读数。
- `reminderCenter`: {open?, filter?: unread|all}——提醒中心：电脑是 K 线工具条铃铛的浮层，手机是整屏提醒页（同一命令；只给 filter 也会打开；游客不可用）；快照 state.reminderCenter {open, filter, unread, today, earlier}；到价提醒 · 生效中的新建表单是 `disclosure: reminder-alert-new`；已读与查看更早走 `POST /api/reminders/read`、`GET /api/reminders`。

## 外观与图表

- `theme`: light / dark / system；`fontScale`: standard / large / extra-large（都是绝对值；“换个主题”“字大一点”先读快照 state.theme / state.fontScale，再写目标值——toggle / larger / smaller 不是合法取值，会被 422 拒绝）。
- `duration`: K线周期（60/180/300/900/1800/3600/86400/604800 秒；任何周期命令都回到 K 线视图）。
- `chartView`: timeshare 分时图（当个交易日的分钟收盘与均价，数据周期钉 60 秒）/ kline 回 K 线；快照 state.chartView。
- `symbol`: 合约切换（口语品种名先经合约目录解析）。
- `chartFocus`: 聚焦某时间范围；`chartAnnotations`: 操作 AI 标注层。
- 画线（2026-10-09 第二版，K 线与分时）都是 `disclosure`：chart-drawing-toolbar（画线工具栏显示 / 收起：平时隐藏，浮在图表左侧，选了工具自己出来、回十字光标就收起；旧名 chart-drawing-tools 同义）、chart-drawing-group {id: lines / levels / fib / shapes / notes / measure}（显示工具栏并展开一组工具）、chart-drawing-tool {id: 工具名，如 trendline / hline / vline / channel / zone / fib / text / measure}（open 开始画，工具栏随之出现，用户在图上点；false 回十字光标，工具栏收起）、chart-drawing-magnet / chart-drawing-lock-all / chart-drawings-hidden（磁吸、全部锁定、全部隐藏，按账号记住）、chart-drawing-clear（全部删除的二次确认，删除本身是 DELETE /api/market/drawings?symbol=）、chart-drawing-style {id: 线 id}（选中一条线，出浮动样式条）、chart-drawing-settings {id: 线 id}（精确设置）、mobile-drawing-style-row {id: color / width / dash}（手机单图选中线后图下条上的颜色 / 粗细 / 线型那一排，要先选中线）、chart-context-menu {id: main / drawing:<线 id> / pane:<kd|macd|rsi|oi>，可加 /draw、/period、/indicator、/add-pane、/style、/swap 打开子菜单}（三种右键菜单，只服务图表，不含下单）。线的 id 在快照 `state.chartDrawings.items`；画、改、删走 chart-drawings 技能的工具或 /api/market/drawings。

## 其他

- `highlight`: 短暂高亮界面元素（rail:ai、panel:strategy、call-bar 等，观察快照的 highlightTargets 是全集）。
- `tour`: {op: next/prev/stop} 新手引导步进。
- 扩展与界面配置：GET/PUT /api/app/config（带 revision 检查），POST /api/app/config/rollback 回滚。

## 读屏

窗口观察快照（GET /api/app/ui/windows/{id}）返回 view、panel、symbol、打开的对话框、可见文字与 highlightTargets——"用户在看哪里"的权威来源。
