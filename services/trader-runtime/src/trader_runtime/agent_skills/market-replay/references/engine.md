# 回放引擎边界

## 支持的操作（control 路由）

- play（播放）、pause（暂停）、step（单步）。
- 一步 = 一根完整的 1 分钟 K 线：走完当前这根（含最高、最低、收盘）并停在下一根的开盘价。没有成交的分钟、午休、夜盘到日盘的空档都在同一步里跨过；当天最后一步走到结算即结束，不越过交易日末。
- 起点：回放就绪时停在当天第一根 1 分钟线的开盘（有夜盘的品种是夜盘开盘，如沪金 21:00；股指 09:30），第一下播放不会跨过开盘前的空白。
- speed：1 / 2 / 5 / 10 步/秒（不是真实时间的倍数，1 步/秒 ≈ 每秒 1 分钟行情）；相对说法（"快一点/慢一点"）在档位间移动。
- close：退出回放（永远可用，不随档位受限）。

## 不支持

- 按时间跳转（"快进到下午两点"）与后退一步：引擎只播放、暂停、单步与四档步速，跳时间会被拒绝并说明。
- 引入回放时刻之后的任何数据：通用 AI 委托在回放中禁用。

## 隔离

- 回放子 Runtime 拥有自己的行情源、账户与卡片命名空间；语音通话经回放命名空间打开时，全部动作作用于回放。
