# 风险预算与价格提醒 v1

## 风险预算

Runtime 读取当前用户已确认的版本化风险规则，并用当前快期模拟账户的 `todayNetPnl` 计算：

- 每日亏损已用额度；
- 每日亏损剩余额度和使用率；
- 单笔最大亏损；
- 当前是否仍在允许开仓时间窗；
- 正常、八成预警、停止开仓或数据不可用状态。

账户快照陈旧、连接中或不可用时，已用额度返回未知，不把占位零值解释为未亏损。实际能否确认交易仍由 Runtime 在最终确认和发送前重新执行确定性风控。

## 价格提醒（到价提醒）

2026-10-02 起为服务端实现（此前为客户端 `localStorage` 方案，已移除）。Runtime 的 `price_alerts` 表按用户（跨账户、跨设备）保存提醒，后台任务每秒检查一次生效提醒：主力合约从报价总表读最新价（只订报价、全站共享 1 秒缓存，不占公共 K 线名额），非主力合约走报价 extras 通道只订报价（每次读 20 个合约，同样不占公共 K 线名额）：

- `symbol` 必须是合约目录里的实际合约；主连（`KQ.m@…`）被拒绝并提示换具体合约；
- 价格按目录 `priceTick` 对齐（Decimal 精确整除检查），不对齐返回 422 中文说明；
- `direction` 可不填：Runtime 按最新价判定（休市或行情不新鲜时按最后成交价，收盘后、节假日照样能设）；现价与目标价相同、或方向已被现价越过时拒绝创建；
- 备注最多 60 个字；每用户全部合约合计最多 20 条生效提醒（422 说明，只是数量上限）；
- 行情新鲜时 `above ≥` / `below ≤` 触发一次；陈旧行情跳过本轮，不触发；
- 触发后经统一提醒入口投递（2026-10-15 #932：`notify.desktop.priceAlerts` 一个开关管全部渠道，关着时到价照样触发、什么都不发；提醒中心一条，`feed.reminder` 弹桌面通知，锁屏推送）：用户正在看的会话（有在线订阅的会话优先，否则最近活跃的会话）落一条持久消息（turnId `pricealert-<id>`）和同一轮的提醒卡（`card.reminder` kind=price_alert：目标价、最新价、时间，按钮只有“问 AI 怎么办”“看图表”）、SSE `feed.price-alert` 数据事件（图上的线与列表移走这条，不再弹通知）、语音通话在线时朗读（回放里触发的提醒只念给绑到同一回放的通话，实盘通话听不到）；
- 接口：`GET/POST /api/market/alerts`、`DELETE /api/market/alerts/{alert_id}`（只删生效中的；已触发的是历史，回 409 与中文原因，不存在或已删回 404）；访客 403；回放子 Runtime 里同样可设（只读回放行情与目录，库随回放一起消失）；AI 走 `create_price_alert` / `list_price_alerts` / `cancel_price_alert` 工具（技能 `price-alerts`）；
- 客户端：提醒面板“我的提醒”那张表（2026-10-31 起到价、画线、条件提醒一起列）增删查看、手机看盘“设提醒”浮层（含“其他合约”折叠）、图上虚线提醒线、右键“价格到 N 时提醒我”与线上的“这条线被碰到时提醒我”（提醒挂在线上，`drawingId`）、设置 → 提醒的“到价提醒”开关（`notify.desktop.priceAlerts`，管对话、桌面通知、语音、锁屏与提醒中心）；已触发的记进提醒中心当天的提醒。

行情快照复用现有共享行情服务（Sidecar 单 `TqApi` 线程和 `wait_update()`），没有第二套行情源。

## 安全边界

价格或风险提醒绝不：

- 调用 `insert_order`、查询或撤销委托；
- 创建平仓、止损或调仓任务；
- 启动策略或自动追价；
- 接触 TqAccount、TqCtp 或实盘账户。

`liveTrading=disabled` 保持不变。提醒只是用户界面信息，不是交易指令。

## 验收

1. 每日亏损达到 80% 时显示预警，达到 100% 时显示停止开仓；
2. 超过用户设置的停止开仓时间显示停止开仓；
3. 账户不可用时风险额度显示未知；
4. 非 tick 网格、目录外合约或与现价矛盾的价格不能创建提醒（422 中文说明）；
5. 正常行情到达阈值时只提醒一次；
6. 陈旧行情不触发提醒；
7. 源码和测试证明提醒路径不调用任何交易动作。
