# TqKq 账户活动只读工作台 v1

## 用户可观察行为

1. 概览直接读取 TqKq 模拟账户快照，不要求先向 AI 提问。
2. 显示多空持仓、总手数、今仓、昨仓、冻结量和浮动盈亏。
3. 显示最近委托与成交；活动委托、部分成交、已成交和已结束状态来自 TqKq。
4. 用户点击“刷新”才重新读取明细，不新增后台轮询、数据库表或本地订单事实。
5. 读取失败时保留已显示的上次快照并明确提示，不用零值或 Fixture 冒充真实账户。
6. 全部接口只读，`liveTrading=disabled`。

## 官方字段

- 持仓：`get_position()` 的 `pos_*_today`、`pos_*_his`、冻结量、开仓均价、保证金和浮动盈亏。
- 委托：`get_order()` 的订单 ID、交易所与合约、方向、开平、总量、剩余量、限价、状态和报单时间。
- 成交：`get_trade()` 的成交 ID、关联订单 ID、合约、方向、开平、价格、数量和成交时间。
- 所有 TqSdk 活动对象仍只存在于 Sidecar 单一 `TqApi` 线程；Runtime 和 UI 只接收普通 JSON 快照。

## 黑盒验收

- 未认证的账户活动接口返回 401。
- 订单和成交历史尚未初始化时不得显示为“无记录”。
- 订单、成交的 `symbol` 必须由 `exchange_id + "." + instrument_id` 生成。
- 持仓今仓、昨仓和冻结量必须保持为独立字段。
- 空账户明确显示暂无持仓、暂无委托和暂无成交。
- 读取账户明细不会调用 `insert_order`、`cancel_order` 或任何平仓接口。
